# Asset Provenance

The Repainted mod is MIT-licensed (see `LICENSE`). That license covers all
code and all assets authored for this mod.

## Paint Palette 3D Model

As of 2.0.0, the paint palette model is an **original work released under
CC0-1.0**, procedurally generated by `palette-designs/generator/`
(reproducible from `variants.json`, entry `B-final`). There are no
third-party licensed assets in this project or its releases.

Historical note: releases prior to 2.0.0 shipped a palette mesh licensed
from TurboSquid (binary-distribution only). That model and its source
archives have been removed from the project entirely.
